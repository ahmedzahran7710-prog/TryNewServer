# أوامر البفات من كونسول السيرفر — أمل الشعوب (Rappelz)

**المصدر:** قوائم أوامر جي إم متداولة على منتديات السيرفرات الخاصة
(elitepvpers · skyeymil · canadian-forum · pcworld.yoo7.com)

## القاعدة

```
add_state( الكود , القيمة , المدة بالمللي ثانية , "اسم اللاعب" )
```

- **الكود** = كود الحالة (state id)
- **القيمة** = قوة الباف (نسبة/نقاط)
- **المدة** = بالمللي ثانية:
  - `600000` = 10 دقائق
  - `3600000` = ساعة
  - `9000000` = **2.5 ساعة** (اللي في المنتديات)
  - `2000000000` = **~23 يوم** (أقصى حد تقني — «دايم»)
- **اسم اللاعب** = بين علامتي تنصيص، ولازم يكون **أونلاين**

**مكان الكتابة:** نافذة **GameServer** (الكونسول الأسود) — يُكتب الأمر في آخر سطر ويُضغط Enter.

| `heal()` / `full_heal()` | علاج |

## ما يجعل الباف «دايم»

1. استخدم `2000000000` كأقصى مدة.
2. أو الأفضل: سكريبت `rz_bless.lua` يعيد التطبيق **تلقائيًا مع كل دخول**،
   فيبقى الباف دائم فعليًا بدون تدخل.

## 🔑 تصحيح مهم من المصادر (كيف تُكتب الأوامر فعليًا)

| المكان | الصيغة | الشرط |
|---|---|---|
| **كونسول السيرفر** (GameServer) | `#add_state(1007,150,9000000,"NAME")` — **بعلامة # في الأول** | لا شيء |
| **شات اللعبة** | `/run add_state(1007,150,9000000,"NAME")` — **بـ /run** | **permission = 100** |
| كونسول السيرفر | `#sv("permission","100","NAME")` | يمنح صلاحية جي إم مؤقتة |

### المصادر
- elitepvpers — «GM permission is 100 / run insert_item in game» (ThunderNikk)
- elitepvpers — «type ingame: /run add_state(1013,10,8640000,"CHARACTER")» (Gangxtar1)
- elitepvpers — «Chat window commands start with /run … permission needs to be set to 100»
- GitHub iKameo/Rappelz-pServer-Commands — `/run add_event_state(9947, 20)` داخل اللعبة،
  و`#add_state(...)` في كونسول السيرفر.

### ملاحظة
جدول `AllowedCommandsForPermission` في قاعدة `Telecaster` هو الذي يحدد أي أمر مسموح
لكل مستوى صلاحية — لو الأمر مرفوض داخل اللعبة، يُفحص هذا الجدول.

## ⚙️ التحكم في قوة الباف (الليفل)

المعامل الثاني في الأمر هو **ليفل الباف** = **قوة الباف**:

```
#add_state( 1007 , الليفل , المدة , "الاسم" )
```

| الليفل | النتيجة |
|---|---|
| `1` | أضعف تأثير |
| `10` | ضعيف |
| `50` | متوسط |
| `150` | قوي (القيمة الشائعة في المنتديات) |
| `250` | قوي جدًا |
| `500` | خارق الحدود الشائعة |

- الليفل يضاعف القيم الموجودة في `StateResource.value_0..value_19`.
- لكل حالة **سقف ليفل** في ملفات اللعبة؛ تجاوزه قد يُقصّ أو يُتجاهل.
- المدة مستقلة تمامًا: نفس الباف يمكن أن يكون ليفل 1 لمدة شهر، أو ليفل 500 لمدة دقيقة.

### أمثلة جاهزة

| الهدف | الأمر |
|---|---|
| هدية بسيطة | `#add_state(1007,10,600000,"NAME")` |
| باف فاعلية | `#add_state(1007,150,9000000,"NAME")` |
| باف أسطوري | `#add_state(1007,500,2000000000,"NAME")` |

### أوامر جاهزة
```
#add_state(4102,10,3600000,"NAME")      هدية خفيفة: 10 xp لمدة ساعة
#add_state(4102,100,9000000,"NAME")     فاعلية: قوي لمدة 2.5 ساعة
#add_state(4113,100,9000000,"NAME")     للمستويات 121-150
#add_state(4116,100,9000000,"NAME")     للمستويات 151-170
```

### مضاعفة الخبرة للسيرفر كله (مش لاعب واحد)
في الكونسول:
```
set game.exp_rate 300
set game.item_drop_rate 200
set game.gold_drop_rate 200
```
- القيمة 100 = الطبيعي · 300 = ٣ أضعاف.
- تُقرأ من `GameServer.opt` السطر `F:game.exp_rate:100`.

## ⚙️ تغيير إعدادات السيرفر (exp_rate / drop_rate) — الصيغة الصحيحة

`set game.exp_rate 300` **غلط** — الكونسول بيقرا لوا، فالصح:

```
set_env("game.exp_rate","300")
set_env("game.item_drop_rate","200")
set_env("game.gold_drop_rate","200")
get_env("game.exp_rate")
```

- `set_env(name, value)` — يغيّر القيمة **في ذاكرة السيرفر فقط** (مش في `GameServer.opt`)،
  فبترجع لأصلها بعد الـ restart.
- `get_env(name)` — يقرا القيمة الحالية.
- الجدول الكامل: `game.exp_rate` · `game.party_exp_rate` · `game.item_drop_rate` ·
  `game.gold_drop_rate` · `game.chaos_drop_rate` · `game.pvp_damage_rate_for_player` …

## 🎁 أوامر إعطاء لاعب بالاسم (مهمة جدًا)

```
add_exp_jp(1000000, 0, "Zahran")        خبرة مليون
add_exp_jp(0, 100000, "Zahran")        100 ألف JP
set_value("gold", 1000000, "Zahran")    ذهب
gv("level","Zahran")                    اقرأ ليفل لاعب
get_state_level(1013,"Zahran")          اقرأ ليفل باف
remove_state(1013,"Zahran")             شيل باف
```

> `set_value(type, value [, charname])` و`add_exp_jp(exp [, jp] [, charname])`
> بيقبلوا **اسم اللاعب** كبارامتر — يعني إعطاء أي لاعب من الكونسول مباشرة.
