## ٣) طريقة التشغيل — ٣ خطوات

### الخطوة ١: نسخة احتياطية
```
backup-rz.cmd
```

### الخطوة ٢: تركيب اللوحة
دبل كليك على **`INSTALL-BOARD.cmd`**

المثبّت يقوم بالآتي أوتوماتيك:
1. يبحث عن `Game_bin\Resource\Script`
2. يعرض **كل الـNPCs** التي لديها حوار
3. تختار رقم NPC واحد (أي NPC — اللاعبون العاديون يظلون يرون حواره الأصلي)
4. يأخذ نسخة احتياطية في `_rzgm_backup`
5. يركّب `NPC_GM_Board.lua` ويضغطه إلى `.ela`

### الخطوة ٣: تشغيل السيرفر
في كونسول اللعبة **لازم** يظهر:
```
[RZ-GM] ---- capability report ----
[RZ-GM] dialog dlg_title = OK
...
[RZ-GM] Board v1.0 loaded.
[RZ-GM] hook installed on NPC_xxx_contact
```

### تشغيل أداة الويندوز
دبل كليك على **`START-GM-TOOL.cmd`** ← `Connect` ← ابحث بالاسم ← علّم `I have a backup` ← نفّذ.

**بيانات الاتصال (جاهزة داخل الأداة):**
`DESKTOP-ICQ037B\SQLEXPRESS` · `Telecaster1` · `rappelz` · باسورد فاضي

## ٤) الاختبار — بالترتيب

### A · اللوحة تفتح
ادخل بـ `OwnerZahran` → كلّم الـNPC المختار → تظهر **RZ-GM Board v1.0**.
ثم كلّمه بشخصية أخرى → يظهر **الحوار الأصلي** (اختبار الأمان).

### B · التقرير 🔴 أهم خطوة
اضغط **[Capability report]** واقرأ الكونسول:

| النتيجة | المعنى |
|---|---|
| `set_value = OK` | ✅ الفلوس تعمل |
| `add_state = OK` | ✅ البافات تعمل |
| `SCRIPT_BroadcastNotice = OK` | ✅ الإعلان للسيرفر يعمل |
| `db_select = OK` | 🚀 ممكن نعمل ربط SQL = **تعديل لأي لاعب لحظيًا** |
| الكل `MISSING` | اللوحة حمّلت لكن الـAPI مختلف — نبني نسخة أخرى |

### C · الفلوس
`Self → Gold → 100000` → شاهد الفلوس + إعلان `[GM] OwnerZahran received: 100000 gold`

### D · أداة الويندوز
`Connect` → ابحث → اختر شخصية → `Set gold` → اخرج وادخل → الفلوس ظهرت.

## ٦) الحدود الحقيقية (مهم)

| العملية | اللوحة | أداة الويندوز |
|---|---|---|
| فلوس/لفل **للشخص اللي فاتح اللوحة** | ⚡ لحظي | عند الدخول التالي |
| فلوس/لفل **لأي لاعب بالاسم** | ⚠️ يعتمد على التقرير | ✅ مضمون |
| **إعلان للسيرفر** | ✅ إذا وُجدت الدالة | ❌ |

**السبب:** محرّك Lua يصل مباشرة إلى اللاعب الذي يخاطب الـNPC. تعديل لاعب آخر يحتاج دالة بحث بالاسم — **والتقرير هو الذي يحدد وجودها**.

**لو ظهر `db_select = OK`** ⇒ نبني جسر SQL ونصبح قادرين على التعديل اللحظي لأي لاعب (النسخة 2.0).

## ٩) استكشاف الأعطال

|---|---|
