# مشروع حقيبة هدية أول دخول 🎁

**الإصدار:** 1.1 · **التاريخ:** 2026-11-10 · **السيرفر:** Rappelz Epic 9.1 (Revolution Team)

> كل شخصية **جديدة** تستلم **حقيبة هدية حسب فئتها**، وبعد فتحها تستلم المحتوى كله **مربوط بالشخصية** (لا تداول · لا بيع · لا تخزين · لا إهداء).

---

## ١) القرارات المعتمدة ✅

| البند | القرار |
|---|---|
| الطقم | **حسب فئة الشخصية** (مقاتل / صياد / ساحر / مستدعي) |
| الأسلحة | سلاح الفئة نفسه |
| من يستلم | **الشخصيات الجديدة فقط** (Trigger على إنشاء الشخصية) |
| الإعلان | **بدون** إعلان سيرفر |
| التسليم | مرة واحدة لكل شخصية — `RZ_GiftLog` |

## ٣) كيف يعمل؟ (الآلية المؤكدة)

```
① 4 حقائب في ItemResource — كل واحدة لفئة:
      script_text   = 'rz_gift_open'
      item_use_flag = 527

② السيرفر يشغّل lua/rz_gift_box.lua   (get_module_name → "rz_gift_open")

③ اللاعب يستخدم الحقيبة → rz_gift_open(id)
      id يحدد الفئة → يُعطي طقمها + المحتوى المشترك

④ الحقيبة تُحذف بعد الفتح
```

### 🔑 بتات `item_use_flag`

| القيمة | يمنع |
|---|---|
| 1 | الإهداء |
| 2 | التخزين |
| 4 | التحسين |
| 8 | **يسمح بالاستخدام** |
| 512 | **التداول** |

| العنصر | القيمة | الحساب |
|---|---|---|
| **الحقيبة · المثبتات · المضاعفات** | **527** | 512+8+4+2+1 |
| **الطقم والأسلحة** | **519** | 512+4+2+1 — **بدون 8** |

> ⚠️ الرقم 8 على العتاد = اللعبة تحاول "استخدام" الدرع = أخطاء.

## ٥) خطوات التنفيذ

### أ) الاكتشاف — ١٥ دقيقة، قراءة فقط
شغّل `sql/01-discover.sql`:

| الاستعلام | بيديك إيه |
|---|---|
| **1** | يتأكد أن `script_text` + `item_use_flag` موجودين |
| **9 / 9b** | **اسم عمود الفئة** في `Character` + القيم الفعلية |
| **10 / 10b** | أطقم مستوى 150 **مقسّمة على الفئات** |
| **11** | بحث بالاسم (Anais / EXP / Energy / Stabilizer) مع أعلام الفئة |
| **6** | **توقيع `smp_insert_item`** — إلزامي قبل التسليم |

### ب) تركيب السكربت
1. `rz_gift_box.lua` → `Game_bin\Resource\Script\`
2. اضغطه → `.ela` · احذف `.lua`
3. رستارت
4. لازم يظهر:
```
[RZ-GIFT] gift box v1.1 loaded. bags = 0 | buffs = 0 | energy = 0 | consumables = 0
```

### ج) تعبئة المحتوى
في السكربت، عدّل:
```lua
RZ_GIFT.buff_items   = { {code, qty, "anais"}, ... }
RZ_GIFT.energy_items = { {code, qty, "energy"}, ... }
RZ_GIFT.consumables  = {
  { code, 20, "activity stabilizer"        },
  { code,  5, "deluxe activity stabilizer" },
  { code, 20, "exp multiplier"             },
  { code,  5, "legendary exp multiplier"   },
}
RZ_GIFT.bags = {
  [<كود حقيبة المقاتل>]  = { label="Fighter",  items={ {..,"armor"}, {..,"weapon"} } },
  [<كود حقيبة الصياد>]   = { label="Hunter",   items={ ... } },
  [<كود حقيبة الساحر>]   = { label="Magician", items={ ... } },
  [<كود حقيبة المستدعي>] = { label="Summoner", items={ ... } },
}
```
ثم أعد الضغط والرستارت — والسطر في الكونسول يعرض الأعداد.

### د) تعريف الحقائب
`sql/02-make-gift-bag.sql` — بعد تعبئة أكواد الـ4 حقائب، وتطبيق 527 على المحتوى و519 على العتاد.

### هـ) التسليم
`sql/03-deliver.sql`:
1. `RZ_GiftLog` (منع التكرار)
2. `RZ_GiftBagMap` (فئة → كود الحقيبة)
3. `RZ_GiveGiftBag` (التسليم)
4. **اختبار** على شخصية واحدة خارج اللعبة
5. تفعيل **الـTrigger** — عندها كل شخصية جديدة تستلم تلقائيًا

## ٧) المخاطر والحماية

| الخطر | الحماية |
|---|---|
| تكرار الأيتم | حذف الحقيبة + `RZ_GiftLog` |
| تلف `dbo.Item` | استخدام `smp_insert_item` (إجراء السيرفر) لا `INSERT` يدوي |
| توقيع `insert_item` مختلف | 3 توقيعات تُجرّب + `pcall` على كل نداء |
| فئة غير معروفة | الإجراء يرفض ويطبع رسالة — لا يعطي حقيبة خطأ |
| العميل يعرض نص قديم | `item_use_flag` يقرأه السيرفر؛ النص يحتاج RDB جديد |
| التراجع | `DROP TRIGGER/PROCEDURE/TABLE` في نهاية `03` |
