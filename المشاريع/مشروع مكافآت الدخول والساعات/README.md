# مشروع مكافآت الدخول والساعات

**Epic 9.1 · سيرفر نسب متوسطة مايل للصعوبة · نسخة 1.1 · 2026-11-10**

> **الوضع الحالي:** النظام مبني ومُختبَر (**٣٩ اختبارًا كلهم ناجحون**) — **وجدول المكافآت فاضي بالقصد**.
> أنت اللي تحدد المكافآت، والنظام ياخدها ويوزّعها. **مفيش أي مكافأة تتسلّم قبل ما تحددها.**

---

## ١) فكرة المشروع

مكافأة يومية على الدخول + مكافأة كل ساعة أونلاين. الأساس اللي بُني عليه:

```
المكافأة تعوّض "مصروف" اللاعب   ✅ آمنة اقتصاديًا
المكافأة تضيف "دخل" للسوق       ❌ تضخم
```

النظام **ما بيفرضش عليك نوع المكافأة**، لكنه بيفرض عليك **حاجتين تقنيتين**:

1. كل أيتم يُسلَّم **مربوط بالشخصية** (`bind bits = 515`).
2. كل مكافأة تمر على **فحص تلقائي** قبل التشغيل (`M.validate()`).

---

## ٢) المفتاح التقني: الربط (Bind)

| البت | القيمة | المعنى |
|---|---|---|
| CANT_DONATE | 1 | لا يُتبرَّع به |
| CANT_STORAGE | 2 | لا يُخزَّن |
| **CANT_TRADE** | **512** | **لا يُتداول ولا يُباع** |
| الإجمالي | **515** | مربوط بالشخصية |

⇒ حتى لو حبيت تحط مكافأة قوية، **مستحيل تدخل السوق**.

## ٣) إزاي تحدد مكافآتك — طريقتين

### 🟢 الطريقة الأسهل: ملف CSV (بدون أي كود)

افتح **`جدول-المكافآت.csv`** (بيفتح في Excel) واملأه:

| النوع | الرقم | الأيتم | الكمية |
|---|---|---|---|
| `daily` | 1 | `repair_kit` | 3 |
| `daily` | 2 | `potion_hp` | 20 |
| `hourly` | 1 | `exp10` | 1 |

- **النوع:** `daily` (مكافأة دخول) أو `hourly` (مكافأة ساعة).
- **الرقم:** يوم كام / ساعة كام (1، 2، 3…).
- **الأيتم:** مفتاح من القائمة في القسم ٥.
- **الكمية:** 1 → 99.
- السطور اللي بتبدأ بـ `#` بتتجاهل.

بعد ما تخلص:
```bash
python3 tests/check_my_table.py           # يفحص الجدول ويقولك أي غلطة
python3 tests/check_my_table.py --write    # يولّد lua/rz_rewards_table.lua من الجدول
```

### 🟡 الطريقة اليدوية: تعديل `lua/rz_rewards_table.lua`

```lua
RZ_TABLE = {
  daily = {
    [1] = { label = "day 1", items = {
      { k = "repair_kit", n = 3 },
      { k = "exp10",      n = 1 },
    } },
    [2] = { label = "day 2", items = {
      { k = "potion_hp", n = 20 },
    } },
  },
  hourly = {
    [1] = { label = "hour 1", items = { { k = "repair_kit", n = 1 } } },
    [2] = { label = "hour 2", items = { { k = "potion_hp", n = 10 } } },
  },
}
```

> **بالتقسيم ده:** `daily[1..7]` = أيام السلسلة، `hourly[1..4]` = ساعات اليوم.
> لو خلّيت يوم فاضي (مثلًا `[4]`) ⇒ اللاعب في اليوم الرابع ما ياخدش حاجة (النظام يقول `nocycle` في اللوج).

## ٤) الفحص التلقائي — إيه اللي بيترفض

| الحالة | النتيجة |
|---|---|
| مفتاح غير موجود (`not_an_item`) | يُرفض + تحذير في اللوج |
| كمية 0 / 500 / 3.5 | يُرفض + تحذير |
| يوم من غير `items` | يُرفض + تحذير |
| الجدول فاضي بالكامل | `no_rewards` — **ولا أيتم يُسلَّم، واليوم ما يُستهلكش** |
| صف فيه غلطة والباقي سليم | الصف الغلط يُتخطّى، والباقي يعمل عادي |

**مهم:** الجدول الفاضي **لا يستهلك يوم اللاعب** — يعني لو ملّيته بعدين في نفس اليوم، يقدر يستلم عادي.

## ٥) المفاتيح المتاحة حاليًا (١١)

```
repair_kit      potion_hp       potion_mp
exp10           exp20           exp30
drop10          teleport_scroll res_scroll
```

عايز مفتاح جديد (مثلًا `my_scroll`)؟ ضيفه في `M.items` جوه `rz_rewards.lua` بكود الأيتم، وبعدين استخدمه في الجدول.

| البند | القيمة الافتراضية | المفتاح |

| مفتاح إيقاف فوري | — | `enabled` |

## ٧) ٦ ثغرات مسدودة

| الثغرة | الحل |
|---|---|
| شخصيات بديلة | العدّاد على **الحساب** |
| خروج ودخول سريع | عدّاد الساعة **ما يتصفّرش** |
| تراكم أوفلاين | لو الغياب ≥ ساعة ⇒ الساعة تبدأ من جديد |
| لاعب غير متصل | `is_online` مطلوب قبل المنح |
| تكرار التسليم | `already` / `cap` |
| مزارع مستوى واطي | حد أدنى 40 |

## ٩) التركيب — 4 خطوات

1. انسخ `rz_rewards.lua` + `rz_rewards_table.lua` + `rz_tick.lua` ⇒ `game_bin/resources/scripts/`
2. أضف جسم `on_login.append.lua` جوه `on_login.lua` (أو سمّيه `on_login.lua` لو مش موجود).
3. املأ `جدول-المكافآت.csv` ⇒ `check_my_table.py --write`
4. حط أكواد الأيتمات في `M.items` (من `sql/01-discover-items.sql`) ثم أعد تشغيل السيرفر.

**اللوج المتوقع:**
```
[RZ-REWARDS] v1.1 loaded | enabled=true | per_account=true | hourly cap=4/day | min level=40 | item codes unset=0 | daily slots=7 | hourly slots=4
[RZ-TICK] TICK-FIRED via on_minute
```
ولو الجدول فاضي:
```
[RZ-REWARDS] REWARD TABLE IS EMPTY -> nothing will be granted. Fill lua/rz_rewards_table.lua
```

## ١٠) عن المؤقت الدوري — بصراحة

`rz_tick.lua` بيعرّف كل الأسماء المحتملة ويقصّها كل ٦٠ ثانية:
`on_minute · on_1min · on_min · run_minute · on_timer · timer_tick · on_second`

- بينادي واحد منهم ⇒ **لحظية** واللوج يقول `TICK-FIRED via …`
- مش بينادي أي منهم ⇒ **مفيش كراش**، واليومية شغالة، والساعية تشتغل بـ`RZ_REWARDS.tick()` من أي NPC
